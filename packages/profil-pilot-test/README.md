# Profil Pilot — Agent test

Version 1.0.0 · MGM Informatique · MIT · Free instructions package.

A small assistant for turning supplied facts into a model listing: title, summary, capabilities, requirements, installation and missing details. It is also an example for checking how a real model appears on a MarketPaperclip test profile.

## Use

1. Extract the archive into its own folder.
2. Read AGENTS.md and the license.
3. Add AGENTS.md as the instruction entry point in a compatible agent runtime you already use. This package does not install or configure that runtime.
4. Run PROFILE_TEST_READY; the documented expected marker is PROFIL_PILOT_OK | 1.0.0 | en.
5. Try a task from examples/tasks.md and review the output.

This is an instructions bundle, not a hosted service, executable application or official import format. A compatible runtime and model access are not included. Provider usage may have its own cost. Runtime execution has not been verified as part of this profile publication test; expected outputs are not recorded test results.

The agent drafts text only. It does not access accounts, post messages, edit profiles or handle payments. Remove its instruction bundle from your runtime to stop using it.
