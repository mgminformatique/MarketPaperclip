# Profil Pilot — Agent test

Version 1.0.0 · MGM Informatique · Licence MIT · Fichier d'instructions gratuit.

Un petit assistant qui transforme vos informations en fiche de modèle claire : titre, résumé, capacités, prérequis, installation et points à préciser. Cet exemple sert aussi à vérifier l'affichage d'un vrai modèle sur le profil de test de MarketPaperclip.

## Utilisation

1. Extraire l'archive dans un dossier séparé.
2. Lire AGENTS.md et la licence.
3. Définir AGENTS.md comme fichier d'instructions dans votre environnement d'agent compatible habituel. Le package n'installe ni ne configure cet environnement.
4. Lancer PROFIL_TEST_PRET. Marqueur attendu documenté : PROFIL_PILOT_OK | 1.0.0 | fr.
5. Essayer une demande dans examples/tasks.md et vérifier la réponse.

Il s'agit d'un bundle d'instructions, pas d'un service hébergé, d'un programme exécutable ou d'un format d'import officiel. L'environnement d'exécution et l'accès au modèle ne sont pas inclus. L'utilisation de votre fournisseur peut entraîner des frais. Aucun lancement dans votre environnement d'agent n'a été vérifié pendant cette publication : les réponses attendues ne sont pas des résultats observés.

L'agent rédige uniquement du texte. Il ne se connecte à aucun compte, ne publie rien, ne modifie aucun profil et ne traite aucun paiement. Retirez son bundle d'instructions de votre environnement pour cesser de l'utiliser.
